# AR Ludo Game

This is a Unity-based Ludo game designed with Augmented Reality (AR) and Artificial Intelligence (AI) in mind. The project includes a robust core game system, customizable rules, and machine learning agents for challenging gameplay.

**Core Game Mechanics**: Fully functional Ludo game logic including dice rolling, pawn movement, safe zones, and capturing mechanics.
**Rules Customization**: A flexible rule system that allows players to customize:
  - Opening roll conditions
  - Safe zone rules
  - Blockade rules
  - Win conditions
  - Consecutive six penalties
**Match Setup & UI**: Functional user interface for the landing screen, game setup, and rules configuration.
**AI Integration**: Implemented ML-Agents for AI opponents, including a training manager and Ludo agent logic to simulate intelligent gameplay.
**Basic Audio System**: Audio manager framework for game sounds.
